# 讲义写作风格指南

## 认知路径

根据课件类型选择对应的认知路径：

### 传统理科课件（物理、化学、材料科学等）

每个知识点的讲解遵循 **直觉类比 → 数学推导 → 物理意义** 的三段式结构：

1. **直觉类比**：用日常经验建立初步认知（用 `> **类比理解：**` 块标记）
2. **数学推导**：严格推导，每步标注依据（用加粗标注关键步骤）
   **数学推导详细度**：讲义越详细越好，不要担心内容过长。即使课件已提供完整推导和关键结论，若逻辑关系无法从上下文中显然得到，必须详细解读每步依据（用了什么原理/定理/公式）。
3. **物理意义**：用 `> **关键洞察：**` 或 `> **重要结论：**` 总结

### 幻灯片课件（CS、AI、工程类等）

每个知识点/算法的讲解遵循 **问题/动机 → 核心机制 → 应用/意义** 的三段式结构：

1. **问题/动机**：为什么需要这个机制？它解决了什么问题？（用 `> **问题背景：**` 块标记）
2. **核心机制/算法**：它怎么工作的？给出公式或伪代码，并用直觉语言解释每一步（用加粗标注关键概念）
3. **应用/意义**：它在实际中如何使用？有哪些变体或改进？（用 `> **关键洞察：**` 或 `> **实际意义：**` 总结）

**常用类比模式（CS/AI 类）：**
- **注意力机制 → 图书馆找书**：你带着问题（Query）在书架（Key）中找到最相关的几本书，然后从中提取你需要的信息（Value）
- **残差连接（Residual Connection）→ 高速公路**：信息可以通过"快捷通道"直接到达目的地，不需要经过每一层的处理
- **位置编码（Positional Encoding）→ 座位号**：给每个词发一个座位号，让模型知道词的相对位置
- **批归一化（Batch Normalization）→ 考试标准化**：把不同量级的成绩统一换算到同一标准，方便比较
- **学习率调度 → 开车换挡**：起步时大步探索（高速挡），接近目标时小步微调（低速挡）

## 公式规范

- 行内公式：`$E = mc^2$`
- 独立行公式：`$$E = mc^2$$`
- 多行公式用 `$$\begin{aligned}...\end{aligned}$$`
- 首次出现的符号必须解释含义

## 类比写作技巧

### 好的类比特征
- 用学生熟悉的日常经验（水流、人群、地形、建筑）
- 只在关键维度上相似，不追求完全对应
- 类比后立即标注"当然这不是精确的对应"

### 常用类比模式
- **DOS → 人口密度**："不是问总人口，而是问每平方公里多少人"
- **费米面 → 水面**：占据态在水面以下，未占据态在水面以上
- **局域化 → 地形障碍**：电子被困在洼地（低能级）无法翻越高地
- **量子限制 → 吉他弦**：弦长确定共振频率，阱宽确定能级间隔
- **弱局域化 → 黑暗中的回声**：电子沿回路回到原点，路径干涉增强回声
- **布里渊区 → 收费站**：带隙处态密度骤降，像收费站中断车流

```markdown
|------|-------|-------|
| 定义 | ... | ... |

```

## 考点编写规范

按题型分类，每个考点包含：
- **考点描述**（一句话）
- **标准答案框架**（概念题）或 **解题步骤**（计算/证明题）
- **常见错误**（可选）

重要程度标记：★★★（必考）、★★（常考）、★（可能考）

## 页码标注规范（核心规则）

讲义的**内容组织严格按课件页码顺序**，标题中直接嵌入页码范围。这是本skill最重要的结构规则——确保学生可以逐页对照原课件自学，不遗漏任何一页。

### 标题格式

页码放在小节编号之后、标题文字之前，用方括号标注：

```markdown
### 2.1 [课件P1] 能态密度（DOS）的定义
### 2.2 [课件P2] 自由电子模型：3D/2D/1D的DOS解析解
### 2.3 [课件P3-P4] 近自由电子DOS与带隙效应
### 2.4 [课件P5] 例题：简单立方晶格s态能带的DOS
```

### 五条铁律

1. **严格递增**：小节页码必须单调递增（P1→P2→P3→...），不允许回跳
2. **连续合并**：连续多页属于同一主题时合并为 `[课件P3-P4]`，但不得超过3页合并
3. **每页必现**：对照表中必须包含课件的每一页。纯图页面也要标注（如 `[课件P19] ARPES实验设备`）
4. **交叉引用不展开**：需要引用后续页面概念时，仅用 `> **注：详见 [课件P15]（第3.2节）**` 提示，不在当前位置展开该后续页面的内容
5. **习题页独立标注**：习题页作为独立小节，给出参考答案框架

### 末尾对照表（自查清单格式）

```markdown
## 六、课件页码自查清单

以下表格覆盖本节**所有**课件页面。每学完一页，在✅列打勾确认。

| ✅ | 课件页码 | 讲义对应章节 | 核心内容 |
|---|---------|------------|---------|
| [ ] | P1 | 2.1 [P1] DOS定义 | DOS定义与k空间推导 |
| [ ] | P2 | 2.2 [P2] 自由电子DOS | 3D/2D/1D解析解 |
| [ ] | P3-P4 | 2.3 [P3-P4] 近自由电子DOS | 带隙效应对比图 |
| [ ] | P5 | 2.4 [P5] sc能带DOS例题 | 等能面与DOS |
| ... | ... | ... | ... |
```

### 例外情况

仅以下两种情况允许不遵从页码顺序：
- **常见误区与辨析**：此节是对全文的总结性对比，不对应特定课件页面
- **考点总结**：此节是跨页面总结，但每个考点应标注对应课件页码

## 写作禁忌

1. 不要使用"显然"、"易得"等跳步用语
2. 不要在类比中引入比原概念更难理解的新概念
3. 不要堆砌公式而不解释每步的含义
4. 不要在推导中间插入无关的旁支知识
5. 不要在讲义中使用emoji（除非用户要求）
6. 不要遗漏任何课件页面的标注——每一页都必须出现在对照表中
7. 不要用英文写讲义——无论课件原文语言，讲义始终用中文撰写
8. 不要因为"课件里已经有了推导"就跳过逻辑关系的讲解

## 语言规范

- **讲义语言**：始终使用中文
- **术语标注**：关键术语首次出现时用括号补充英文原词（如"自注意力机制（Self-Attention）"）
- **公式**：保持原样（通常是英文变量名和数学符号），公式后的解释用中文
